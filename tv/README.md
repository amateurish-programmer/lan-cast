# 电视接收端

要求 Android TV 8.0+（API 26），IPv4 家庭局域网。电视与手机连接同一 Wi-Fi / 网线网络；访客网络的 AP 隔离可能阻止访问。

1. 打开电视 App，把电视上显示的 IPv4 地址（手机地址框只填 IP）和六位码输入手机。
2. 本地视频使用 Media3 播放；可通过手机暂停/继续或电视遥控器控制。
3. 实验性影音镜像播放手机提供的 H.264/AAC MPEG-TS 实时流。源 App 可能禁止音频采集或使受保护画面黑屏。实时镜像不提供暂停/快进；停止后重新开始。
4. 选择“全屏播放”隐藏配对面板；遥控器返回键退出全屏。退出 Activity 会断开手机并停止接收。
5. “检查更新”读取公开 GitHub 最新发布信息，并由用户打开发布页、下载 tv APK 手动安装。无浏览器的电视可由手机/电脑下载后通过 U 盘安装。没有自动安装或后台更新。

## 协议

监听 TCP 8765。所有命令要求手机来自 RFC1918 IPv4；不支持 DNS 主机名、IPv6、回环地址或公共互联网地址。

- POST `/pair`，JSON `{"code":"123456"}`，返回 `token`、`expiresInSeconds` 和 `protocolVersion`。
- POST `/play`，JSON `{"url":"http://手机IP:8766/media/<capability>"}`。
- POST `/mirror`，JSON `{"url":"http://手机IP:8766/stream/<64位十六进制capability>"}`。
- POST `/pause`、`/resume`、`/stop`。实时镜像的暂停/继续返回 409。
- GET `/status`，返回当前模式、播放状态、时间和错误。

除配对外均需 `Authorization: Bearer <token>`。会话绑定发起配对的手机 IP，最长两小时。配对码五分钟轮换，最多每分钟五次尝试；电视更换配对码立即断开旧会话。播放请求在主线程执行前会重新校验会话。更换网络后重新配对。

## 安全边界

仅在可信任的家庭局域网使用。此原型使用明文 HTTP，局域网内有能力监听流量的攻击者可能看到媒体与令牌。配对并不提供加密或抵御同网中间人攻击。

媒体 URL 只能指向当前手机的私有 IPv4、端口 8766 和精确路径，不允许查询参数、账号信息、片段或跳转。媒体数据源直接连接 IP，禁用代理和 HTTP 重定向，采用 ProgressiveMediaSource，不载入远程播放列表。控制服务限制并发连接和 JSON 请求大小，并拒绝浏览器 Origin 请求。
