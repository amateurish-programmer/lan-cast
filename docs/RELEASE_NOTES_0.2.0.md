# v0.2.0 · 自动发现与大屏体验

- 手机重新设计深色界面：设备卡片、连接状态、操作分区与清晰提示。
- 电视统一深色视觉：连接卡片、明确的遥控器焦点与全屏播放控制。
- 自动发现局域网内正在运行的本项目电视接收端，不再输入 IP 或 PIN。
- 手机请求连接，电视明确允许 / 拒绝；支持取消、超时、限速和断开。
- 手机网络变化后停止共享并作废会话；旧请求不能覆盖新的投屏操作。
- 手机和电视均可在应用内查看新版本说明、下载并校验 APK，再打开系统安装器。
- 更新严格校验固定仓库 URL、SHA-256、APK 包名、递增版本号与原有签名。

注意：本版本仍是 debug 签名测试版，传输为可信局域网内的明文 HTTP。自动发现仅支持本项目接收端；不是通用 Chromecast/DLNA 客户端。不绕过 DRM 或应用采集限制。尚未完成 vivo S20 Pro / Sony KD-65X9088H 真机与实际系统升级验收。
